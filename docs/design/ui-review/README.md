# TaelgarVerse UI design review

Open [TaelgarVerse-UI-Review.html](TaelgarVerse-UI-Review.html) in a current
Chrome, Edge, Firefox, or Safari browser. The standalone export includes its
styles, scripts, page excerpts, and images. No internet connection, running
TaelgarVerse server, installation, or ChatGPT account is required.

Use the five **Design** buttons at the top to compare Classic Encyclopedia,
Modern Codex, Atlas Reference, Reader's Edition, and Quiet Library. Choose
**Page** and **Section preview** directly below them. Each design includes
System, Light, and Dark appearance options.

The review contains Chardon, Addermarch, Voltara, Melusa, the Green Sea, and
Dunmari Frontier Sessions 110 and 120. Long sections are excerpted and marked
when they continue. This is a design snapshot from October 19, 2026; it does
not update when vault content changes.

Page and section selection, contents groups, design switching, and appearance
controls work locally. World navigation and references inside article text are
illustrative. This is a design comparison, not the live site.

To share, send the HTML file as an attachment. Recipients should download it
and open it in their browser; GitHub's source preview does not run the controls.

Validation: page and design switching, dark mode, and embedded image loading
were checked in a browser. External script dependencies were removed for the
offline export.
