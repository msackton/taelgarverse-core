Taelgarverse 0.2.0

- Add an optional image viewer inside Taelgarverse. Enable Image viewer in settings; it is off by default and applies immediately in Reading View and Live Preview.
- Enlarge images with fit-to-screen, full-resolution download, pan/zoom, mouse and keyboard controls, and authored captions from image callouts, gallery items, and session figures.
- Honor inline left/right image placement, named sizes, centered figures, full-width heroes, and responsive galleries without a separate vault CSS snippet.
- Preserve linked images, modified clicks, local originals, and note contents. Disabling the feature removes its controls and closes its viewers. Map tiling remains website-only.
- Hide the Leaflet label and flag on Taelgarverse maps.

Desktop only. The minimum app version remains Obsidian 1.8.0.
