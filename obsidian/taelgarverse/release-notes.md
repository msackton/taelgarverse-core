Taelgarverse 3.1.0

- Use the geographic root Taelgar in whereabouts indexes to list regions and other places directly or recursively, without needing a separate Taelgar note.
- Build catalogs from a required frontmatter filter, such as a list of every plane. Catalogs can include notes with no recorded whereabouts.
- Add an Origin column to tables and sort by it. Origin uses the recorded home at birth or creation.
- Customize generated index headings and individual column labels while keeping the original column keys for sorting.

Requires Obsidian 1.8.0 or newer.
