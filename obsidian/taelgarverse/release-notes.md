Taelgarverse 0.5.3

- Add **Show header index popups** in Taelgarverse settings. Turn it off to hide Members, Residents, and other generated-header index buttons in Obsidian while keeping website popups and inline index tables and grids.
- Apply the setting immediately to open notes and close any open header index popup. The setting defaults to on and is saved across restarts.

Reload Taelgarverse after updating, then turn off **Show header index popups** if desired.

Desktop only. The minimum app version remains Obsidian 1.8.0.
